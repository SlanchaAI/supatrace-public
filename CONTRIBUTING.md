# Contributing to SupaTrace

SupaTrace is maintained by Slancha, Inc. Bug reports, documentation fixes, and pull requests are welcome. Discuss a large behavior change in an issue before building it. General questions can go to oss@supatrace.dev. See [SECURITY.md](SECURITY.md) for private vulnerability reports.

## Local setup

Use Node.js 22+, Python 3.12, Git, and OpenSSL. Follow the [README](README.md#run-locally) for a loopback server with synthetic accounts and in-memory data. No cloud or payment credentials are needed.

```sh
npm ci --ignore-scripts
npm test
```

The root test command runs Node and Python suites. Run the suites relevant to your change:

```sh
# JavaScript SDK
npm --prefix packages/supatrace-js ci --ignore-scripts
npm --prefix packages/supatrace-js test
# Python SDK
PYTHONPATH=packages/supatrace/src:agent python3 -m unittest discover -s packages/supatrace/tests -p 'test_*.py'
# Model Context Protocol bridge
npm --prefix mcp ci --ignore-scripts
npm run test:mcp
# Browser tests (requires Chromium)
npm run test:ui
```

See [UI test setup](docs/ui-tests.md) and the CI workflow for browser installation and optional OpenTelemetry test dependencies. Use synthetic data. Do not use production accounts, cloud credentials, or live payment keys for tests.

## Changes and pull requests

Work on a branch. Keep each change focused and add a test when it checks behavior that could regress. Describe the problem, resulting behavior, and validation in the pull request. Link a related issue when one exists. Maintainers review changes before merging; no response or merge time is guaranteed.

Read files before editing them. Keep prose short. Shared site blocks are generated by `scripts/site-pages.mjs`; edit their source and run `node scripts/site-pages.mjs --write`. Other generated assets name their generator. Commit generated output with its source.

Do not commit credentials, trace content from real users, local configuration, or test artifacts. Do not weaken authentication or transport security to make a test pass. Changes to hosted-service policies need maintainer review.

No contributor license agreement (CLA) is required. Developer Certificate of Origin (DCO) sign-off is optional. Contributions are made under the repository's Apache-2.0 license, subject to existing third-party licenses. Follow the [code of conduct](CODE_OF_CONDUCT.md).
