Framework guide

LlamaIndex

Record LlamaIndex model calls as SupaTrace events from Python.

Python SDK: Beta. JavaScript SDK: Coming soon. Install the alpha Python package with pip install supatrace==0.1.0 (Python 3.10+). The JavaScript supatrace package is not published to npm; its examples run from the public repository root. For a first hosted trace, use the stock OpenTelemetry exporter or the Python/Node snippets on Home.

Record a call in source mode Beta

Source mode is the default. It makes no network request: you choose the events, the SDK checks them against the same batch rules the server applies and writes one file to a local spool for you to review. The example records the model name and token counts, not the prompt or the reply.

pip install supatrace==0.1.0
Scroll for more →
import datetime
import supatrace
from llama_index.llms.openai import OpenAI

trace = supatrace.init(service="support-bot", spool="./spool")
now = lambda: datetime.datetime.now(datetime.timezone.utc).isoformat()

started = now()
reply = OpenAI(model="YOUR_MODEL").complete("Say hello.")
result = trace.batch([
    {"id": "req-1", "time": started, "kind": "request", "name": "OpenAI.complete", "data": {"model": "YOUR_MODEL"}},
    {"id": "res-1", "time": now(), "kind": "response", "name": "OpenAI.complete", "data": {"output_chars": len(reply.text)}},
])
print(result["report"]["valid"], result["report"]["path"])

Review, then upload

Open the spooled file and read it. Remove anything you do not intend to store. Then upload it with the script from the setup guide, using the write-only connection you approved there:

python3 upload.py ./spool/BATCH.json --config ./supatrace-access.json
Scroll for more →

The trace appears under Traces in your workspace. Batch limits apply: 100 events and 512 KiB per batch.

Automatic spans over OTLP Beta

With mode="otlp" the Python SDK registers the openinference-instrumentation-llama-index instrumentor when it is installed and exports spans to SUPATRACE_OTLP_ENDPOINT + /v1/traces, authenticated with your write key. SupaTrace accepts traces over OTLP/HTTP on supatrace.dev. The Python SDK is an alpha package on PyPI; framework instrumentation has local tests but no hosted acceptance proof. For the first trace, use a stock exporter from the OpenTelemetry guide today. LlamaIndex is not in the default instrument list; name it in instruments.

pip install "opentelemetry-sdk>=1.27" "opentelemetry-exporter-otlp-proto-http>=1.27" openinference-instrumentation-llama-index
export SUPATRACE_OTLP_ENDPOINT="https://supatrace.dev"   # SupaTrace SDK OTLP mode (Python Beta; JavaScript source only)
export SUPATRACE_API_KEY="YOUR_WRITE_KEY"
Scroll for more →
import supatrace

trace = supatrace.init(service="support-bot", mode="otlp", instruments=["llama_index"])
print(trace.capture["sending"], trace.capture["instrumented"], trace.capture["skipped"])
Scroll for more →

Nothing is sent unless the endpoint, the key and the OpenTelemetry packages are all present. When one is missing, trace.capture["skipped"] says which. Prompt and response content is not captured unless you pass capture_content=True or set SUPATRACE_CAPTURE_CONTENT=1.
