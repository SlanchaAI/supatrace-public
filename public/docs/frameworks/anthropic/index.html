Framework guide

Anthropic

Record Anthropic Messages API calls as SupaTrace events from Python.

Coming soon. The Python and JavaScript supatrace packages are not published to PyPI or npm. Until then send traces with the stock OpenTelemetry exporter or the Python/Node snippets on Home. These SDK examples run from the public repository checkout.

Record a call in source mode preview

Source mode is the default. It makes no network request: you choose the events, the SDK checks them against the same batch rules the server applies and writes one file to a local spool for you to review. The example records the model name and token counts, not the prompt or the reply.

pip install ./packages/supatrace   # from the public repository root
import datetime
import supatrace
import anthropic

trace = supatrace.init(service="support-bot", spool="./spool")
now = lambda: datetime.datetime.now(datetime.timezone.utc).isoformat()

started = now()
reply = anthropic.Anthropic().messages.create(model="YOUR_MODEL", max_tokens=256, messages=[{"role": "user", "content": "Say hello."}])
result = trace.batch([
    {"id": "req-1", "time": started, "kind": "request", "name": "messages", "data": {"model": "YOUR_MODEL"}},
    {"id": "res-1", "time": now(), "kind": "response", "name": "messages", "data": {"input_tokens": reply.usage.input_tokens, "output_tokens": reply.usage.output_tokens}},
])
print(result["report"]["valid"], result["report"]["path"])

From Node, use the same trace.batch pattern as the OpenAI Node example. The JavaScript SDK has no automatic Anthropic instrumentation.

Review, then upload

Open the spooled file and read it. Remove anything you do not intend to store. Then upload it with the script from the setup guide, using the write-only connection you approved there:

python3 upload.py ./spool/BATCH.json --config ./supatrace-access.json

The trace appears under Traces in your workspace. Batch limits apply: 100 events and 512 KiB per batch.

Automatic spans over OTLP SDK preview, package coming

With mode="otlp" the Python SDK registers the opentelemetry-instrumentation-anthropic instrumentor when it is installed and exports spans to SUPATRACE_OTLP_ENDPOINT + /v1/traces, authenticated with your write key. SupaTrace accepts traces over OTLP/HTTP on supatrace.dev. The SupaTrace SDK remains a checkout-only preview, unavailable to outside users; use a stock exporter from the OpenTelemetry guide today. 

pip install "opentelemetry-sdk>=1.27" "opentelemetry-exporter-otlp-proto-http>=1.27" opentelemetry-instrumentation-anthropic
export SUPATRACE_OTLP_ENDPOINT="https://supatrace.dev"   # checkout-only SupaTrace SDK preview
export SUPATRACE_API_KEY="YOUR_WRITE_KEY"
import supatrace

trace = supatrace.init(service="support-bot", mode="otlp", instruments=["anthropic"])
print(trace.capture["sending"], trace.capture["instrumented"], trace.capture["skipped"])

Nothing is sent unless the endpoint, the key and the OpenTelemetry packages are all present. When one is missing, trace.capture["skipped"] says which. Prompt and response content is not captured unless you pass capture_content=True or set SUPATRACE_CAPTURE_CONTENT=1.
