Reference

Management API

Read what your workspace shows from a script: workspaces, projects, keys, usage, traces and the ingest log. The API is read-only and lives under /api/v1.

Create a personal access token

Open Settings in your workspace, name a token and choose when it expires (1 to 365 days, 30 by default). Your browser makes the token (stpat_…) and sends the server only its SHA-256, so the token is shown once and cannot be recovered.

  • Read-only. A token can call the GET endpoints below. It cannot upload, create or revoke keys, change billing or manage tokens.
  • Account-scoped. A token sees what your account can open, with your current role in each workspace. Removing the account from a workspace removes the token's access to it.
  • Revocable. Revoke a token in Settings. It stops working at once.
  • Up to 20 tokens for an account.

Call the API

Send the token in the X-Supatrace-Key header:

curl -H "X-Supatrace-Key: $TOKEN" https://supatrace.dev/api/v1/projects

A server you run yourself also accepts Authorization: Bearer $TOKEN. On supatrace.dev the edge replaces the Authorization header before it reaches the API, so use X-Supatrace-Key there.

Errors are JSON of the form {"error": "code"}. A missing, expired or revoked token is 401. A workspace the account cannot open, or a route its role may not call, is 403. Each token may make 120 requests a minute; 429 carries Retry-After.

Endpoints

RequestReturns
GET /api/v1/meThe account and the token making the request
GET /api/v1/workspacesWorkspaces the account can open, with its role in each
GET /api/v1/projectsProjects. A workspace has one project
GET /api/v1/keysKeys of a workspace environment: id, type, expiry, revoked. Needs a role that may manage keys. Key values are never returned. Up to 100 keys a page; follow next with after
GET /api/v1/usageStored bytes, limit and plan state of a workspace
GET /api/v1/logsRecorded upload attempts of a workspace environment, newest first, with the reason when one was refused. stream (issues or accepted), route, reason, from, to, limit, after
GET /api/v1/tracesTraces. limit, offset, sort, dir, q, from, to
GET /api/v1/traces/{trace_id}/eventsThe events of one trace, one stored batch per page. Follow next with after

Workspace endpoints take workspace (defaults to the account's own) and, except usage, environment (defaults to default). A parameter that is not listed for an endpoint is refused with 400.

Secret keys

A secret key (st_sec_…, created under API keys) is also accepted on GET /api/v1/traces and GET /api/v1/traces/{trace_id}/events. It reads only the workspace and environment it belongs to. A workspace or environment parameter naming another one, and every other /api/v1 endpoint in the table above, returns 403 key_scope_denied. The OpenAPI document needs no credential. Ingest keys (st_pub_…) and setup-code keys cannot read. See Keys.

OpenAPI document

GET /api/v1/openapi.json serves the OpenAPI 3.1 description of these endpoints. It needs no token. The repository's tests call every operation in it and check each response against its schema.

Not available yet

  • Write operations: creating or revoking keys, changing workspaces, billing.
  • Token scopes narrower than the whole account, and OAuth apps.
  • Rate limits that vary by plan.
  • Rendered reference pages for each endpoint. The OpenAPI document is the reference.
