Importers

For a hosted first trace, use Home snippets, hosted OTLP or the reviewed scripts today.

Bring history from another tool. File and API importers stage reviewed batches on your machine first; nothing uploads until you run the uploader. The Langfuse import runs in the workspace after you review its exact scope.

Provider file imports Coming soon

Convert one export file you chose into SupaTrace batches. Formats: LangSmith runs, Braintrust span logs, Weave calls, Opik spans, Datadog LLM Observability JSON, MLflow traces, Helicone request logs and OTLP HTTP JSON (not protobuf or gzip).

Not available in the hosted service yet. Local staging source is in the public repository and needs Node 22 and Python 3.12; the converters are not part of the setup guide downloads. Uploading requires deployment-specific hooks. It does not call provider APIs or capture live sessions. The setup guide has a command builder.

node agent/import_traces.mjs ./reviewed-export.json langsmith source-project-name proj_REPLACE_WITH_32_HEX_CHARACTERS ./private-import

The default keeps metadata only: IDs, timing, span kinds, error status and token counts. Add --include-content to keep prompts, outputs and other source fields, after you have reviewed them for secrets. The command stages locally and reports uploaded:false.

LangSmith and Braintrust API imports Coming soon

Not available in the hosted service yet. Operator-run importers live in the public repository. They read 1 to 25 completed traces you name from the LangSmith or Braintrust API, checkpoint privately and stage the same uploader manifest. These need deployment-specific upload hooks and your own provider key; the hosted workspace does not run them. There is no recurring sync, project discovery or live capture. These have source tests; a hosted end-to-end acceptance run is still open.

Langfuse Beta

Under Agents, Import from Langfuse prepares an exact scope: one Langfuse project, trace, environment and UTC time window. You review that scope and consent to reading and storing it, enter your Langfuse read keys once and start. While the page stays visible it advances the import in small bounded requests and reports progress; you can pause and resume. The keys are sent only to SupaTrace and the Langfuse region you chose, are kept only during the active import and are not saved.

Limits: 100 observations, 10 pages, 50 rows per page and 128 KiB of source JSON per import. There is no recurring sync or background worker.

Server pull runs only where the server has it enabled. That is an operator setting; the stack template's default enables it for supatrace.dev. A verified import from a real Langfuse account on the hosted site is still open (#67), which is why this is beta.

Claude Code

  • Snapshot Live: convert one finished transcript you select with claude_snapshot.py. See the setup guide.
  • Hooks Beta: an opt-in command hook that records prompt, tool and completion events into a private spool. Metadata only by default. See the setup guide.
