Quickstart

Your first trace

Start with Home: one ingest key and a curl, Python or Node snippet, about 30 seconds after sign-in. Next, send OTLP from any OpenTelemetry exporter. Use the reviewed scripts when an agent needs approval. The Python SDK is on PyPI; the JavaScript npm package is Coming soon.

1. Send a trace from Home Live

  1. Sign in. A new workspace shows Send your first trace on Home.
  2. Select Create ingest key and show snippets. Your browser makes an ingest key (st_pub_…) and sends the server only its SHA-256. The key is shown once, filled into curl, Python and Node snippets.
  3. Run one snippet. It posts a small synthetic chat call to /api/batches and needs no package install.
  4. The card shows the trace when the upload is accepted. Open it from there.

The ingest key can only send traces. It does not expire; revoke or rotate it under API keys. Ingest keys from Home or the API keys page do not expire by default; keys from pairing an agent last 30 days. See Keys.

2. OTLP from any OpenTelemetry exporter Live

Send traces to supatrace.dev over OTLP/HTTP with protobuf or JSON. No SupaTrace package is needed. No gRPC, metrics or logs. See the OpenTelemetry guide for limits.

Create an ingest key on Home or the API keys page. Ingest keys from Home or API keys do not expire by default; keys from pairing an agent last 30 days. In a fresh shell, set these two variables, replacing only YOUR_INGEST_KEY:

export OTEL_EXPORTER_OTLP_ENDPOINT=https://supatrace.dev
export OTEL_EXPORTER_OTLP_HEADERS="x-supatrace-key=YOUR_INGEST_KEY"
Scroll for more →

Both x-supatrace-key: <key> and Authorization: Bearer <key> are accepted. The environment-variable alternative is OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer YOUR_INGEST_KEY". Some SDKs require the space URL-encoded: Authorization=Bearer%20YOUR_INGEST_KEY, following the OpenTelemetry header format.

Try HTTP/JSON

This fake span calls no model provider. Replace the key before sending:

curl -X POST https://supatrace.dev/v1/traces \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_INGEST_KEY' \
  -d '{"resourceSpans":[{"scopeSpans":[{"spans":[{"traceId":"11111111111111111111111111111111","spanId":"1111111111111111","name":"synthetic.example","startTimeUnixNano":"1794685870000000000","endTimeUnixNano":"1794685871000000000"}]}]}]}'
# Or replace Authorization with: -H 'x-supatrace-key: YOUR_INGEST_KEY'

The base URL makes both stock exporters append /v1/traces. Leave any OTEL_EXPORTER_OTLP_TRACES_ENDPOINT and OTEL_EXPORTER_OTLP_TRACES_HEADERS overrides unset.

Python

pip install opentelemetry-sdk opentelemetry-exporter-otlp-proto-http
Scroll for more →

Save as first-trace.py. It sends one synthetic span over HTTP/protobuf and flushes before exit.

from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import SimpleSpanProcessor
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter

provider = TracerProvider()
provider.add_span_processor(SimpleSpanProcessor(OTLPSpanExporter()))
trace.set_tracer_provider(provider)
with trace.get_tracer("first-trace-example").start_as_current_span("synthetic.chat") as span:
    span.set_attribute("gen_ai.provider.name", "example")
    span.set_attribute("gen_ai.request.model", "synthetic-model")
    print("Trace: otlp." + format(span.get_span_context().trace_id, "032x"))
provider.force_flush()
provider.shutdown()

Scroll for more →

These compatible package versions keep the trace SDK and exporter on the same OpenTelemetry API version. Save as first-trace.mjs (ESM). This JavaScript exporter reads the same two environment variables and appends /v1/traces to the base URL. It sends HTTP/JSON.

import { trace } from "@opentelemetry/api";
import { BasicTracerProvider, SimpleSpanProcessor } from "@opentelemetry/sdk-trace-base";
import { OTLPTraceExporter } from "@opentelemetry/exporter-trace-otlp-http";

const provider = new BasicTracerProvider({
  spanProcessors: [new SimpleSpanProcessor(new OTLPTraceExporter())],
});
trace.setGlobalTracerProvider(provider);
const span = trace.getTracer("first-trace-example").startSpan("synthetic.chat");
span.setAttribute("gen_ai.provider.name", "example");
span.setAttribute("gen_ai.request.model", "synthetic-model");
console.log("Trace: otlp." + span.spanContext().traceId);
span.end();
await provider.forceFlush();
await provider.shutdown();

3. Send a trace with the reviewed scripts Live

You need Python 3, a terminal and a SupaTrace sign-in. The setup guide has the script downloads, the full steps and the recovery notes. In short:

  1. Sign in, open Agents in your workspace and copy your project ID.
  2. Download connect.py, upload.py and first-trace.json from the setup guide into one folder. Read them before running them.
  3. Create a write-only connection. The script shows a 12-character setup code; approve only that code in your workspace.
    python3 connect.py --project YOUR_PROJECT_ID --config ./supatrace-access.json
    Scroll for more →
  4. Upload the reviewed synthetic example and wait for Accepted by server.
    python3 upload.py ./first-trace.json --config ./supatrace-access.json
    Scroll for more →
  5. Open Traces, select Refresh Traces and open first-trace-example.

The key in supatrace-access.json is a setup-code key: it can upload but cannot read traces, lasts 30 days and can be revoked. Keep the file private. See Keys.

Both write the same file for the same batch: spool/<sha256>.json. An event has an id, a time, a kind (request, tool_call, tool_result, response, error or note), a name and a data object. Pass dry_run=True (Python) or dryRun: true (JavaScript) to validate without writing.

import supatrace

trace = supatrace.init(service="checkout", spool="./spool")
report = trace.batch([{"id": "e1", "time": "2026-11-14T00:00:00Z", "kind": "note", "name": "hello", "data": {}}], dry_run=True)["report"]
print(report["valid"], report["errors"], report["path"])

Review, then upload

Open the spooled file and read it. Remove anything you do not intend to store. Then upload it with the script from the setup guide, using the write-only connection you approved there:

python3 upload.py ./spool/BATCH.json --config ./supatrace-access.json
Scroll for more →

The trace appears under Traces in your workspace. Batch limits apply: 100 events and 512 KiB per batch.
