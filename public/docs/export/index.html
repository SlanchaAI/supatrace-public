Reference

Export

Your traces are yours to take. Export one trace, one environment or every environment in a workspace as JSON from the workspace app.

Export one trace

Open a trace under Traces and choose Export original JSON. The file has every accepted event of that trace with its original fields. In browsers with Save File support the export streams to disk; other browsers are limited to 20 MiB and 100,000 events per trace.

Export an environment or the workspace

Export selected environment reads only the environment shown in the workspace switcher. It is not a complete export when the workspace has more than one environment.

Export all workspace environments includes every listed environment in the workspace, after you confirm that scope. It does not include other workspaces.

How the archive is saved depends on the browser:

  • With Save File support, you pick a file first and the archive streams straight to it. The status line reports the archive as saved; there is no separate download step.
  • Without Save File support, the app prepares the archive in the tab, limited to 20 MiB and 100,000 events in total. When the status line says the archive is ready, choose Download prepared archive, then check your browser downloads.

Pause uploads while an export runs: the archive is an observed read, not a point-in-time snapshot.

Review before sharing

  • Exports are not automatically redacted. They can contain prompts, tool output, personal information and secrets.
  • Prepare redacted copy masks paths and exact text you select, locally, for one trace. Its input limit is 2 MiB. It does not change stored traces, does not apply to environment or workspace archives and does not guarantee anonymity.
  • Exports preserve event fields, not the original uploaded batch bytes.
  • Exports contain only data inside its retention period. On Free that is 7 days from when a batch was accepted; export before then. Data stored before retention existed has no expiry and stays exportable.

Read traces from an agent with MCP preview

The repository includes a local stdio MCP server with four tools: list traces, search traces, inspect one trace and export one trace. It requires a private checkout and is unavailable to outside users. With that access it runs on your machine, inside a project scope you review, and returns event IDs, times and kinds unless you opt in to content. It is not a hosted MCP endpoint. Write keys cannot read, so it needs a host that supplies a short-lived read credential; the browser consent flow for that is off by default on the hosted alpha.

Not available yet

There is no scheduled export. To forward batches as they arrive, add a trace drain (a signed HTTPS webhook) under Settings in your workspace. To list traces and read their events from a script, use a personal access token with /api/v1. File exports run in a signed-in browser.
