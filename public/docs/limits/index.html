Limits

These are the limits the service enforces. Plan limits come from the plan table; payments for Base and Pro are in Stripe test mode until launch.

Current limits

AreaLimit
Free allowance50k spans per UTC calendar month and 1 GB stored, per organization. Base, Pro and Enterprise raise both; see Pricing. A span is one accepted trace event. The span count resets on the first of the month; stored bytes count accepted and pending uploads and do not reset. At either limit uploads are rejected with an error that names the limit; nothing already stored is dropped.
Retention7 days on Free, 30 on Base, 90 on Pro and 1 year on Enterprise, counted from when a batch is accepted. After that it is no longer listed, opened or exported. Data stored before retention existed does not expire.
Service capacity1,000 accounts and 50 GiB across the service during the test-mode launch. This shared cap can stop an upload before an organization reaches its own allowance. Both caps must be raised before live Stripe is activated; 50 GiB is below one Enterprise allowance.
Projects per organizationFree 2, Base 3, Pro 10, Enterprise 20. Projects share billing and usage; keys, environments and traces are isolated. A third Free project is refused with HTTP 402 plan_limit_reached.
Batch1 to 100 events and 512 KiB per batch; 32 KiB per event's JSON data; nesting depth 32.
Rate60 API requests per minute per network; 30 uploads per minute per account.
KeysActive keys per organization follow the plan: 2 on Free, 10 on Base, 25 on Pro, 100 on Enterprise. Ingest and secret keys do not expire unless you set an expiry; keys made with a setup code expire after 30 days. Setup codes expire after 10 minutes.
Claude snapshotInput at most 20 MiB. Finished transcripts you select; not a live tailer.
Trace listing100,000 run IDs, 20 MiB of metadata and five minutes per scan.
Export without Save File support20 MiB and 100,000 events.

The setup guide has the recovery steps for each limit.

Not in the alpha

  • Live payments remain off; Base and Pro checkout and upgrades use Stripe test mode.
  • Individual-trace deletion is unavailable. Account, organization, project and environment deletion revoke access and queue physical erasure.
  • Expired data is hidden immediately; the scheduled worker erases payload versions and releases stored bytes. Recovery backups expire within 35 days.

Use synthetic or deliberately reviewed data for evaluation.
