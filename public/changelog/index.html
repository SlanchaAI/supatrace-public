Changelog

What changed.

A curated list of user-visible changes, taken from merged pull requests. Dates are the UTC day each pull request merged. "Deployed" means the change is on the branch production deploys from; "merged, not deployed" means it is waiting for a release.

Last production deploy recorded here: November 13, 2026 (commit 0a800c0).

  1. November 14, 2026

    Per-plan retention

    Each batch is stamped with its plan retention when accepted (30 days on Free) and stops being listed, opened and exported after that. Expired data is hidden, not deleted.

    merged, not deployed Pull request #157

  2. November 14, 2026

    Security and Enterprise pages

    A /security page states storage, encryption and access facts and what is not in place (no SOC 2, DPA or HIPAA). An /enterprise page shows the proposal and marks SLA terms as pending.

    merged, not deployed Pull request #150

  3. November 14, 2026

    Build marker

    A release writes the served commit to /build.json and the footer shows it, so anyone can tell which build a site serves.

    merged, not deployed Pull request #147

  4. November 14, 2026

    Monthly Free allowance

    The lifetime 10 MiB cap is replaced by a Free allowance of 50,000 spans per UTC calendar month and 1 GB stored. The span count resets monthly; stored bytes do not.

    merged, not deployed Pull request #142

  5. November 14, 2026

    Ingest from Langfuse SDKs

    An app on a Langfuse SDK can send traces by changing the host and keys. Ingest only. Hosted routes answer; SDK compatibility remains beta with local acceptance only.

    merged, not deployed Pull request #152

  6. November 14, 2026

    OTLP/HTTP trace ingest

    A receiver at POST /v1/traces accepts OpenTelemetry traces as protobuf or JSON. Available on supatrace.dev for traces only; no gRPC, metrics or logs.

    merged, not deployed Pull request #141

  7. November 14, 2026

    Integrations directory

    An /integrations page lists frameworks, providers, importers and agent tools, each marked available, beta, preview or planned.

    merged, not deployed Pull request #145

  8. November 14, 2026

    Docs site

    A /docs site with a quickstart, framework guides and reference pages for keys, limits, export and importers. It marks the SDKs as unpublished.

    merged, not deployed Pull request #144

  9. November 14, 2026

    Proposed pricing page

    A /pricing page shows proposed Free, Pro, Team and Enterprise plans. It is labelled a proposal; no plan can be bought.

    merged, not deployed Pull request #138

  10. November 14, 2026

    Python and JavaScript SDK prototypes

    Source for a supatrace Python package and an @supatrace/client JavaScript package that validate and spool batches locally. Repository only; not on PyPI or npm.

    merged, not deployed Pull request #132

  11. November 12, 2026

    Setup links and clearer key list

    A setup link opens Agents with the setup code filled in. The key list shows when each key was created and marks the newest one.

    deployed Pull request #79

  12. November 11, 2026

    Langfuse import from the workspace (beta)

    Import one exact Langfuse trace scope from Agents in bounded, resumable steps. It runs only where the server has it enabled; a verified import from a real account on the hosted site is still open.

    deployed Pull request #63

  13. November 9, 2026

    Crawl files, share tags and a 404 page

    robots.txt, sitemap.xml, llms.txt, canonical and social tags, and a real not-found page.

    deployed Pull request #60

  14. November 9, 2026

    Create a write key from the dashboard

    A signed-in owner can create a write key from the dashboard.

    deployed Pull request #57

  15. November 6, 2026

    Workspace and environment switching

    The workspace and environment switcher stays available across the dashboard.

    deployed Pull request #43

  16. November 6, 2026

    Workspace roles and environments

    Owners can invite existing accounts as Admin or Viewer and create environments that share the workspace quota.

    deployed Pull request #39

  17. November 5, 2026

    Braintrust and LangSmith import handoff

    Agents can prepare a reviewed import spec for the local Braintrust and LangSmith importers. Nothing is fetched or uploaded from the browser.

    deployed Pull request #30

  18. November 5, 2026

    Read-only MCP trace server

    A local stdio MCP server that lists, searches, inspects and exports traces within a reviewed scope. Requires a private checkout and is unavailable to outside users.

    deployed Pull request #23

  19. November 5, 2026

    Braintrust API import

    A local importer that reads 1 to 25 completed Braintrust traces you name and stages them for review.

    deployed Pull request #21

  20. November 5, 2026

    Provider file imports

    Convert export files from LangSmith, Braintrust, Weave, Opik, Datadog LLM Observability, MLflow, Helicone and OTLP JSON into reviewed batches on your machine.

    deployed Pull request #20

  21. November 5, 2026

    Clearer outcomes for interrupted archive exports

    Stalled account archive file operations now time out and can be retried. A save that could not be confirmed is reported as unconfirmed, not as success; an interrupted export is not resumed.

    deployed Pull request #15

  22. October 27, 2026

    supatrace.dev and supatrace.tech

    Both hostnames are served from one deployment.

    deployed Pull request #9

  23. October 25, 2026

    Signed-in dashboard

    The signed-in workspace is restored, and its address without the trailing slash redirects to it.

    deployed Pull request #6

  24. October 24, 2026

    Traces on one screen

    The trace view is one screen with no page scroll.

    deployed Pull request #3
