Integrations

What connects
to SupaTrace.

Frameworks, providers, importers and agent tools. Each one carries the status it has today, and links to the guide that shows exactly what it does.

available
Usable today on supatrace.dev or through public downloads.
beta
Implemented with source tests; hosted or real-client acceptance is still open.
preview
Private-checkout feature, unavailable to outside users. SDK packages are coming; not on PyPI or npm.
planned
Not usable today.

Standards

  • OpenTelemetry (OTLP ingest)

    available

    OTLP/HTTP receiver for any OpenTelemetry exporter, protobuf or JSON. Available on supatrace.dev for traces only; no gRPC, metrics or logs.

    Read the guide: OpenTelemetry (OTLP ingest)

  • Langfuse SDKs

    beta

    Point an app that uses a Langfuse SDK at SupaTrace by changing the host and keys. Ingest only. Hosted routes answer; SDK acceptance is local only, so this remains beta.

    Read the guide: Langfuse SDKs

  • OTLP JSON file

    preview

    OTLP HTTP JSON export files (not protobuf or gzip). Checkout-only converter, unavailable to outside users while the repository is private. Use Home snippets or hosted OTLP today.

    Read the guide: OTLP JSON file
