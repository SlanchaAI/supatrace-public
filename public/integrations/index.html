Integrations

What works with SupaTrace.

Start with what works today. Everything else is under Coming soon.

Live

  • OpenTelemetry (OTLP)

    Send traces with any OTLP/HTTP exporter, protobuf or JSON. Traces only. No gRPC, metrics, or logs.

    Read guide: OpenTelemetry (OTLP)

  • Claude Code snapshot

    Convert one finished transcript you choose into batches. This is not a live tail.

    Read guide: Claude Code snapshot

Beta

  • Langfuse SDKs

    Point a Langfuse SDK at SupaTrace by changing the host and keys. This only receives traces.

    Read guide: Langfuse SDKs

  • Langfuse import

    Import one exact trace scope from the workspace with your Langfuse read keys.

    Read guide: Langfuse import

  • Claude Code hooks

    An opt-in hook that records prompt, tool, and completion events into a private spool. Metadata only by default.

    Read guide: Claude Code hooks
Coming soon

Until these ship, use Home snippets or hosted OTLP.

  • LangChain, LlamaIndex, Vercel AI SDK, OpenAI, Anthropic

    SDK packages are not on PyPI or npm yet. LangChain, LlamaIndex, and Vercel can send traces today with stock OpenTelemetry or AI SDK telemetry.

    Read guide

  • OTLP JSON file, LangSmith, LangSmith API, Braintrust, Braintrust API, Weave, Opik, Datadog LLM Observability, MLflow, Helicone

    Private checkout only. LangSmith API and Braintrust API read 1 to 25 completed traces you name.

    Read guide

  • MCP reader

    Not a hosted MCP endpoint.

    Read guide
